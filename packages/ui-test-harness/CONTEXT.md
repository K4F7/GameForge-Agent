# UI Test Harness

外置验收控制层的领域上下文。它从外部驱动并观察保持原版的 CodeArts TUI 与 OpenChamber GUI，按权威状态判定通过，并把两个被测面的时间线关联到同一份可复核记录。

跨上下文术语（`Authority`、`Evidence`、`Observer`、`Sidecar 事件`、`薄适配代码`）定义在 `docs/glossary.md`，本文件只使用、不重复定义。

## 语言

### 被测与观察

**被测对象**：
保持上游原版、由本框架从外部驱动的交互界面，当前为 CodeArts TUI 与 OpenChamber GUI。框架不为容纳测试而改造它们。
_Avoid_: 产品 UI、前端、Workbench

**观察窗**：
渲染唯一 ConPTY 同一 VT 流的独立可见窗口。它是同一个会话的第二个视图，不是第二个会话。
_Avoid_: 终端面板、嵌入终端、第二会话

### 环境

**常驻测试环境**：
由本框架持有、跨多次运行复用的无凭据 loopback 依赖集合。它的生命周期独立于任何一次运行。
_Avoid_: 测试环境（过泛）、开发环境、dev 环境

**外部依赖**：
运行所必需但**不**由本框架持有的部分，当前指 CodeArts 客户端及其认证与私有数据目录。框架只探测它，不接管它。
_Avoid_: 第三方服务、上游依赖

**预检**：
运行开始前对每项依赖作出的可达性判定，以及依赖缺失时给出的补救指引。
_Avoid_: 健康检查、探活、ping

### 运行档位

**环境就绪检查**：
一次不要求 Agent 完成任务的有头运行，回答「这套验收环境现在能不能用」。它的通过**不**构成对产品行为的任何断言。
_Avoid_: 冒烟 / smoke（仓库中已指 Provider 与平台 CLI 探针）、自检、健康检查

**真实验收**：
一次要求真实 Task 与 Run 均由 Authority 判定完成的有头运行。只有它的通过才构成端到端已验证的结论。
_Avoid_: 端到端测试、E2E、集成测试

### 结果

**诊断**：
一次失败运行的分类结论，及其指向该次运行原始 Evidence 的索引。它是对已有证据的导航，不是新的事实来源。
_Avoid_: 错误报告、日志、报错信息

**门禁**：
判定一次运行通过与否的条件集合。不同档位的门禁不同，且任一档位的门禁都不得被另一档位的结果替代。
_Avoid_: 断言、检查项、验收标准
