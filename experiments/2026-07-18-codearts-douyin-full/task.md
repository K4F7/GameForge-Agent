# 任务

让真实 CodeArts 26.6.2 非交互 CLI 通过 GameForge MCP 独立完成一个抖音小游戏的本地生产 Run：

1. 创建并认领 Task，绑定 MCP Audit；
2. 检查能力和模型路由，产出严格 GameSpec；
3. 先预演再生成 LayaAir 抖音小游戏项目；
4. 验证类型获胜路径与超时失败路径；
5. 使用 LayaAir CLI 3.4.0 生成抖音小游戏包；
6. 发布连续 RunEvent 并完成 Run。

固定输入为 `definition.json`。本实验使用程序化素材，不调用媒体 Provider；验收终点是无 GUI 本地玩法与静态包构建，不宣称打开抖音开发者工具、真机运行、上传或发布。
