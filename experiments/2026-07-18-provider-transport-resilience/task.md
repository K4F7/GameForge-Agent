# 实验任务

日期：2026-07-18

为百炼 Qwen、Seedream、Freesound 搜索/preview 与火山异步 TTS 增加共享的有界 HTTP 可靠性边界：超时、结构化错误、有限退避、响应体释放与响应大小限制。不得调用真实付费 API，不得把非幂等生成请求伪装成可安全重试。

## 验收条件

1. 408、429、5xx、超时和网络错误可分类，认证/授权错误不重试；
2. 默认最多三次，退避和 `Retry-After` 均有 60 秒硬上限；
3. 终态错误与超限响应取消 body，不回显凭据或上游错误正文；
4. Seedream 与 TTS submit 默认只发送一次；查询和下载路径可有限重试；
5. 四类 Provider 通过本地 mock 测试，整仓门禁通过。
