# Workbench 新任务生命周期实验

## 目标

让 Run ID 幂等安全与多任务用户体验同时成立：失败重试保留原 ID，新需求显式生成新 ID，连接期间不能把控制请求误发给另一个 Run。

## 验收条件

1. 页面加载时生成符合 Schema 的唯一 Run ID，不使用固定 `run-local`；
2. Task 提交并连接后锁定 Run ID 输入；
3. 当前 Run 未终止时拒绝准备新任务；
4. 停止后点击“新任务”生成不同 ID；
5. 清除旧 Task 回执、规格、资产、预览、日志和阶段状态；
6. 右侧活动 Run 显示 `NO RUN`，不残留旧 Run ID；
7. 真实 Chrome 截图人工检查通过。
