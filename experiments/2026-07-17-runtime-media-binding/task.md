# 运行时媒体绑定任务

让生成游戏安全消费已落盘的图片、音效、配音与背景音乐，并修复 Freesound `bgm` 导入与 Asset Store 类型约束不一致的问题。

验收条件：

1. 浏览器只加载契约允许的角色、MIME、相对路径和唯一角色；
2. 缺失或损坏条目不阻断程序化玩法回退；
3. `bgm` 只在用户首次交互后循环播放；
4. Freesound 的普通预览记录为 `sound`，明确的 BGM 记录为 `music`；
5. 新生成工程通过自身 TypeScript 检查与构建；
6. 带真实 WAV BGM 的生成工程通过系统 Chrome 启动验收；
7. Bun 整仓门禁通过。
