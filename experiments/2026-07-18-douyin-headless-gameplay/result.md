# 实验结果

状态：五种玩法逻辑测试通过。

`bun run --filter @gameforge/generator test -- douyin-headless.test.ts` 实际执行 24 项生成器测试，其中新增 5 项玩法证据全部通过：

| genre | 输入/状态控制 | 已证明结果 |
|---|---|---|
| arcade | 把唯一收集物放入玩家碰撞范围并推进一帧 | `score=1`、收集物清空、`status=won` |
| puzzle | 连续两次 `ArrowRight` 并推进一帧 | 玩家从 x=96 到 x=192，收集并胜利 |
| platformer | 推进到地面、按 `ArrowUp`、再触发收集 | 重力落地、跳跃 y 下降、最终胜利 |
| shooter | 把唯一危险物放在玩家右侧、按 `Space` | 子弹移除最终危险物、`score=1`、胜利 |
| strategy | 初始 2 条生命、切换激进姿态并碰撞 | 单次扣除 2 条生命、`status=lost` |

宿主只实现生成源码使用的显示树、事件、loader、声音空操作和手动时钟；资产 Manifest 明确走无素材回退。它不实现 `tt` API、Laya 渲染器、音频解码、触摸坐标换算、生命周期或包加载，因此这组结果只证明生成的 TypeScript 玩法分支和遥测状态机可执行，不能替代官方 Laya 构建、抖音 DevTool 或真机验收。

人工干预：选择每类玩法的最短确定性输入路径；未修改生产模板源码。射击测试固定移动危险物的测试初始位置，以消除时间漂移，命中仍由生成源码的子弹更新和碰撞逻辑完成。
