# Multi-agent v2 回归诊断任务

## 原始任务

检查 `multi_agent_v2` 在 `gpt-5.6-sol`、`gpt-5.6-terra` 和 `gpt-5.6-luna` 上的派生能力，结合历史日志判断问题是否与 Codex 版本相关，并对 WebSocket 启用和禁用两种连接方式做实测。

## 验收条件

1. 新建独立会话，不以主线程中的文字声明代替真实协作工具事件。
2. 覆盖 CLI 0.144.4 与 0.144.5、WebSocket 开与关、三种目标模型。
3. 从 `state_5.sqlite` 和 rollout JSONL 中统计历史 v2 子线程的真实完成结果。
4. 记录模型、CLI 版本、耗时、协作工具、错误、人工干预和最终结论。
5. 不输出或提交令牌、密码、账号信息和完整私有会话内容。
